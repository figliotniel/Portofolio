## 🌟 Fitur Utama (Key Features)

- 🌐 **Dukungan Dua Bahasa (Bilingual)**: Beralih secara instan antara Bahasa Indonesia (ID) dan Bahasa Inggris (EN) dengan penyimpanan preferensi pengguna.
- 🌓 **Tema Gelap & Terang (Dark / Light Mode)**: Palet warna *high-contrast tech* yang nyaman di mata dengan sinkronisasi `localStorage` dan deteksi preferensi sistem (`prefers-color-scheme`).
- 📱 **Desain Mobile-First & Responsif**: Tata letak yang dioptimalkan untuk berbagai ukuran layar—dari smartphone compact, tablet, laptop, hingga monitor desktop.
- ⚡ **Zero Heavy Framework**: Dibuat murni menggunakan Vanilla HTML5, Modern CSS3 kustom (CSS Variables, Flexbox, CSS Grid), dan ES6+ JavaScript untuk performa kilat dan jejak memori minimal.
- ♿ **Aksesibilitas & Semantik**: Struktur HTML semantik, atribut ARIA pada kontrol interaktif, serta navigasi keyboard yang ramah pembaca layar.
- 📸 **Galeri Proyek Interaktif**: Carousel screenshot responsif untuk meninjau dokumentasi proyek dan alur aplikasi.

## 🚀 Menjalankan Secara Lokal (Getting Started)

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/figliotniel/Portofolio.git
   cd Portofolio
   ```

2. **Buka halaman:**
   - Cukup buka file `index.html` langsung di browser favorit Anda, atau
   - Gunakan extension seperti **Live Server** di VS Code / editor pilihan Anda.
